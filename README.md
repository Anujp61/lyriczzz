# lyriczzz

A small macOS player that sits on the camera bar and shows whatever is playing, with lyrics.

Click the island for lyrics. Drag it anywhere. Drop it on the camera bar and it snaps home. Open **Look & Feel** to change the color, how see-through it is, and the shape.

It can start on its own when Spotify opens. That check runs every few seconds and then exits, so it stays light.

## Run

```bash
./build.sh
open Lyriczzz.app
```

Needs macOS 14 or later.
